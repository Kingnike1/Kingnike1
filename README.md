## 🚀 Sobre Mim

Formado em **Informática para Internet** pelo **IF Goiano – Campus Ceres** e atualmente graduando em **Engenharia de Software** na **Unialfa**.

Minha trajetória é marcada pela transição do aprendizado acadêmico para a construção de sistemas robustos e escaláveis.

Tenho foco em:

* resolução de problemas complexos;
* arquitetura de software;
* organização estrutural de aplicações;
* desenvolvimento fullstack;
* aplicações web e mobile.

Minha abordagem técnica é analítica: não apenas escrevo código, mas penso em toda a estrutura da aplicação — desde modelagem de banco de dados até experiência final do usuário.
